# 0007 — 按子服务分类接入插件

- 日期：2026-09-13
- 变更类型：`Added` / `Changed` / `Security` / `Docs`
- 范围：插件协议、环境管理 API、独立插件包、前端配置流程

## 变更

- 接入实例独立保存环境、子服务、连接配置、凭据、默认限制和运行时状态，同一插件可重复接入。单实例更新与移除原子提交，其他接入保持原值；快照保存无凭据的归属与配置。
- 新增 PostgreSQL、SSH 主机诊断、SSH 日志三个独立包，归入数据库、主机诊断、日志类别。PostgreSQL 使用只读事务、AST 与表列限制；SSH 采用已验证指纹和固定检查；远程日志用只读 SFTP 复用文件日志解析器，并限制路径、枚举与扫描预算。
- 分类元数据加入插件公开列表；新增子服务创建/编辑 API。已经绑定的环境和子服务不可直接迁移，旧目录、旧快照及环境级接入保留兼容。
- 前端按“环境 → 子服务 → 添加插件 → 类别 → 配置”操作，自动绑定数据源与生成标识，预填常用默认值，分别反馈保存和检查，保留冲突草稿；提交期间禁止切换配置范围。
- 安装器与 plugins extra 提供五个参考连接器；连接按环境与子服务按需配置。CI 纳入插件源码检查、独立包构建和前端表单回归。

## 验证与状态

已实现。使用 fake 连接验证查询限制与配置隔离，不调用真实模型。前后端类型/格式/回归检查、独立构建，以及隔离目录中的桌面与 390px 浏览器流程验证通过。真实 PostgreSQL/SSH 目标需由使用者提供连接配置后验证。
