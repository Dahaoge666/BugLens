# SSH 日志检索插件

独立包 `buglens-ssh-logs-plugin`，插件 ID `ssh_logs`，日志类别。复用 SSH 连接设置与文件日志解析器，依赖它们的独立插件包，不导入 BugLens 后端。

在环境中选择子服务 → 添加插件 → 日志 → SSH 日志，填写主机、连接账号、远端绝对日志目录，以及目录内相对文件名（支持多行）。密码、私钥与指纹配置独立于同主机的其他接入；无需部署远端探针，不建立本地下载缓存。

通过 SFTP 仅以 `rb` 打开文件。路径不得包含 `..`、绝对文件名、反斜杠或递归 `**`；通配符只允许位于文件名，如 `archive/*.log`。逐级 lstat 拒绝文件和中间目录符号链接，并检查规范化路径仍位于配置 root 内。远端账号应只拥有所需日志目录的读取权限。

固定文件名自动包含轮转文件。日志格式、编码、时间/文本/级别/服务/节点/关联 ID 筛选和匹配条数 cursor 与文件日志一致；时间必须绝对且不超过 24 小时。目录枚举、扫描文件数、实际读取字节、返回条数/字节和 deadline 均有上限；目录枚举被截断时不返回完整分页承诺。引用使用相对文件名与行号。连接检查验证 SSH 和目录权限，实际文件权限在查询时验证。

仓库安装：`uv sync --project backend --extra web --extra plugins`。独立构建：在本目录执行 `uv build`。配置示例见 [远程环境示例](../../backend/config/environments.remote.example.yaml)。
